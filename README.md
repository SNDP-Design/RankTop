# RankTop AI - Autonomous Multi-Agent AI Swarm Engine

> **RankTop AI** is an autonomous multi-agent search engine optimization (SEO), answer engine optimization (AEO), and generative engine optimization (GEO) platform built with React, Vite, Tailwind CSS, and Google Gemini AI.

## ✨ Features

- **Master SEO, AEO & GEO Command Center**: Live performance telemetry scorecards, organic clicks growth curve, keyword ranking distribution, and LLM answer engine citation rates.
- **Autonomous AI Swarm Center**: Multi-agent orchestrator managing specialized AI agents (Research, Writer, Schema, Competitor, Voice/AEO, Publisher).
- **Keyword Strategy & Topic Clusters**: High-opportunity, low-KD keyword discovery engine with search intent filtering.
- **AI Writer & Editor**: Long-form 2,000+ word article generator with automated headings, key takeaways, FAQ sections, and BlogPosting JSON-LD schema markup.
- **Google AI Overview & Voice Search Inspector**: Test content snippet citation probability in Google AI Overviews and voice search assistants.
- **LLM Search Visibility (GEO Hub)**: Audit crawler access for GPTBot, ClaudeBot, PerplexityBot, and Google-Extended.
- **Competitor Keyword Gap Analysis**: Extract high-value ranking gaps between your domain and rival websites.
- **Direct CMS Auto-Publishing**: Connect WordPress, Webflow, Shopify, or Ghost via REST API webhooks for 1-click publishing.

## 🛠️ Local Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/SNDP-Design/RankTop.git
cd RankTop

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

# 4. Build for production
npm run build
```
